# Blinkfy candidate growth slice

This slice completes the first usable candidate growth journey in the Talent workspace:

1. The candidate sees profile positioning completeness, discoverability, consent count, and next actions.
2. The candidate can generate a resume draft for a target role.
3. The candidate can generate a post, comment, or connection-note draft for a value network.
4. Generated assets remain explicitly unpublished and require candidate approval.

The UI consumes the existing authenticated Talent endpoints; no LinkedIn scraping, autonomous publishing, or unsolicited outreach is introduced. This is the free-candidate foundation for future paid engagement capabilities.
