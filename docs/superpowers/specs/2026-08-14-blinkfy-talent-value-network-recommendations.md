# Blinkfy Talent — value network recommendations

Candidates can now ask Blinkfy to find relevant connections from the private
connection metadata available in their profile. Matching uses target role and
skills, is capped at 20 results, and returns only a minimal identity and role.

The endpoint and UI are recommendation-only: no connection request, message,
comment, or publication is sent. Any future engagement must remain an
explicit candidate-approved action and respect the existing consent and
entitlement policies.
