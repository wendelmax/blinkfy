# Blinkfy Screen review slice

The hiring pipeline now presents the existing screening summary as a human-review checkpoint. Recruiters can see whether consented evidence is complete, which evidence types are available, and the current score before reviewing recordings, transcripts, or insights.

The interface intentionally labels automated output as support only: it does not reject, shortlist, or make a hiring decision. This is the UI completion of the Screen dossier contract and prepares the next slice for explicit reviewer feedback and scheduling.
