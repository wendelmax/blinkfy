# Blinkfy Screen structured recruiter feedback

The screening dossier now supports auditable structured feedback with four assessments: positive, neutral, negative, and needs review. Each entry requires a reviewer note, is persisted against the application, and creates an audit event.

Feedback is contextual evidence for human decision-making. It never changes pipeline stage, rejects a candidate, or overrides a score automatically. The API also refuses feedback until the screening session has recorded consent.
